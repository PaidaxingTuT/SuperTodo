# 清单 · 个人超级清单工具

一个**个人专享**的清单管理应用，统一记录购物 / 待办 / 计划 / 旅游 / 愿望。

- **形态**：本地网页应用（PWA），手机浏览器 `添加到主屏幕` 后可全屏当 App 用
- **数据**：本地存储（localStorage），不联网、不上云，可导出/导入备份
- **风格**：Google Material 蓝，简洁清爽，可自定义配色
- **技术**：纯原生 HTML + CSS + JavaScript，无任何框架 / 依赖

---

## 一键使用

在手机上打开 `index.html`（或通过本地服务器），浏览器里即可使用。如需像 App 一样全屏，用 Chrome/Safari 打开后选 **添加到主屏幕**。

## 核心功能

### 三层信息架构
| 层级 | 是什么 | 在哪 |
|------|--------|------|
| **一级** | 类型（购物/待办/计划/旅游/愿望…） | 左上角 ☰ 汉堡菜单 |
| **二级** | 分组（按场景或按时间） | 主页大区块卡片 |
| **三级** | 具体待办事项 | 点进二级区块后看到 |

### 记录
- 右下角 **＋** 一键添加，顶部无横向筛选
- 完整表单：标题 / 备注 / 类型 / 场景 / 时间 / 预估花费 / 截止日期 / ★重要程度
- 点击已有事项可编辑 / 删除

### AI 速记
- 右下角 **✨** 一句话速记：输入一句话，AI 自动解析类型 / 场景 / 时间 / 花费 / 截止日期 / 重要度，填好表单确认保存（需先开启 AI 增强）
- 设置 → AI · 云端增强 → 打开「**启用 AI 增强**」开关，填写 OpenAI 兼容接口的 base URL / key / 模型名；未开启时速记按钮不显示
- 解析到不存在的标签时提示「建议新建」，默认勾选可取消
- 设置弹窗 → 数据 → **智能整理**：扫描未分类 / 未分组事项，AI 逐条建议场景 / 时间，列表预览 + 一键采纳（需开启 AI 增强）

### 分类与排序
- 三类标签（类型 / 场景 / 时间）全部可自定义增删改
- 列表页右上角排序按钮：花费（升/降）、重要度、截止日期、创建时间、默认（手动顺序）
- 「默认」排序下，列表页按住右侧 **≡ 把手** 可手动拖拽调整顺序，落位即保存
- 完成事项自动沉底

### 全面自定义
| 想改什么 | 操作方法 |
|---------|---------|
| **配色** | 汉堡菜单 → 设置 → 外观·主色：预设 10 色 + 自定义取色器 |
| **类型（一级）** | 汉堡菜单里**长按**某类型 → 重命名/删除；或汉堡菜单底部"＋新增类型" |
| **场景/时间** | 汉堡菜单 → 设置 → 相应区块：点名字重命名、✕ 删除、＋ 添加 |

### 数据管理
- 汉堡菜单 → 设置 → 数据：导出备份 / 导入备份 / 清空全部

## 开发说明

- 无需构建，直接打开即可
- 开发期已禁用 Service Worker（避免旧缓存），**打包 APK 时需重新启用** `sw.js`
- 代码为纯原生 ES6，`esprima` 可校验 JS 语法
- 数据版本 key：`listapp.data.v2`

## 打包与发布（GitHub Actions 一键）

- **Android APK**（主）：推送 `v*` 标签，workflow 自动用 Capacitor 封装 WebView 壳并构建 **app-debug.apk**，发布到 Release，手机直接下载安装：

```bash
git tag v2.8 && git push origin v2.8
```

- **在线网页版**（可选）：push 到 `main` 自动部署 GitHub Pages。首次需在仓库 **Settings → Pages → Source** 选择「GitHub Actions」
- App 内「检查更新」从 GitHub Release 获取最新版本（需仓库发布过 `v*` Release）
